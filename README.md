# Kigali Self-Driving Car Simulation

## Project Description
This project simulates a self-driving car travelling along a road in Kigali, Rwanda. The car responds to road signs, follows speed limits, stops at zebra crossings, and changes lanes when necessary.

## Project Files
- **index.html** – Displays the driving simulation in a web browser.
- **engine.py** – Handles the simulation's web server.
- **road_simulation.py** – Contains the road layout and the main simulation functions.
- **transit_program.py** – Controls the driving simulation.
- **README.md** – Provides information about the project.

## How to Run the Project
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   `python road_simulation.py`

4. Enter the driver's name.
5. Choose option 5 to start driving.
6. Open the displayed local web address in your browser.
7. Press Enter in the terminal when prompted.

## Project Outcome
The simulation demonstrates how a self-driving car can respond to different road signs and safely travel from ALU Rwanda to the Convention Center.
